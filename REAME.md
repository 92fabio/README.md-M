## Condições 
> if, switch, ternarios

Condições é o *métado* para **validar** se uma ***informação*** é verdadeira_ a __condição__ ___aplicada___ `if` executa somente o codigo que esta dentro dele, com isso temos condições para que o códico execute somente o necessário

```csharp
if (valor1 == valor2){
    MessageBox.Show("Os números são iguais");
}
```

```js
if (valor == valor2){
    console.log("Os numeros são iguais");
}
```

```php 
if ($valor1 == valor2){
    echo "Os números são igauis";
}
```

```python
if valor1 == valor2:
    print("Os valores são iguais")
```
